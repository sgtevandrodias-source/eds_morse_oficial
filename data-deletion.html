EDS MORSE – Exclusão de Dados

Esta página explica como solicitar a exclusão de dados associados ao aplicativo EDS MORSE, desenvolvido por EDS Ideas Factory.

Quais dados podem ser excluídos?

O EDS MORSE não exige cadastro obrigatório. Quando o usuário participa do Ranking Global, podem ser armazenados dados como Nome de Operador, pontuação, nível alcançado e estatísticas relacionadas ao jogo.

Como solicitar a exclusão?

Para solicitar a exclusão dos dados relacionados ao Ranking Global, envie um e-mail para:

edsideasfactory@gmail.com

No e-mail, informe:

  • Nome de Operador usado no app;
  • Solicitação clara de exclusão dos dados do Ranking Global;
  • Se possível, informe que o pedido se refere ao aplicativo EDS MORSE.

Após o recebimento da solicitação, os dados associados ao Nome de Operador informado serão analisados e removidos do Ranking Global, quando identificados.

Dados armazenados localmente no dispositivo podem ser apagados pelo próprio usuário ao limpar os dados do app ou desinstalar o aplicativo.

EDS MORSE – Data Deletion

This page explains how to request deletion of data associated with the EDS MORSE app, developed by EDS Ideas Factory.

What data can be deleted?

EDS MORSE does not require mandatory registration. When the user participates in the Global Ranking, data such as Operator Name, score, level reached and game-related performance statistics may be stored.

How to request deletion?

To request deletion of data related to the Global Ranking, send an e-mail to:

edsideasfactory@gmail.com

In the e-mail, include:

  • The Operator Name used in the app;
  • A clear request to delete Global Ranking data;
  • If possible, mention that the request refers to the EDS MORSE app.

After receiving the request, the data associated with the informed Operator Name will be reviewed and removed from the Global Ranking when identified.

Data stored locally on the device can be deleted by clearing the app data or uninstalling the application.
